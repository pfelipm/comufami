# Proyecto ComuFami

Instrucciones específicas para el desarrollo de este proyecto.

## Flujo de trabajo
- **Sincronización:** realizar siempre un `clasp push` inmediatamente después de cualquier modificación de código para mantener el entorno de Apps Script actualizado.
- **Documentación:** mantener el `README.md` actualizado con los cambios significativos en la arquitectura o funcionalidades.
